The obvious inference -- write the cursor explicitly -- is wrong, and it is

seven compile to the same object**, four bytes shorter than the target with the
first mismatch at +0x64 and 77 masked words. So the retained byte-offset
spelling is not one of a family; it is the only member of the family that keeps
the word the target keeps, and the cursor is not reachable by respelling this
loop.

`tools/register_census.py` reads the naming half as 85% coherent over two
windows with two closed cycles in the dominant mapping, s6 against s7 and a1
against s5. That is an L127 shape and it is the part of this residual most
likely to move at zero byte cost -- but it sits behind the structural word, so
the order of work is the loop first.

Decision variable: what stops uopt from strength-reducing this loop when the
address is written as a byte offset. Both reads use the same induction variable
with the second at a constant displacement, which is the case strength reduction
normally takes; the guard `if (*exceptions != -1)` ahead of the loop and the
compound exit condition are the two candidate causes, and neither has been
varied.
